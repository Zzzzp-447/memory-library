# 教材目录读取

读取顺序：

1. 按来源 PDF 的文件标识匹配人工核验过的目录。
2. 读取 PDF 内置书签。
3. 没有书签时，读取前 32 页中的目录文字；只接受目录标题和页码等证据，不从正文猜测章节。

纯扫描 PDF 没有文字层，当前不做自动 OCR。未核验版本会明确提示没有读取到目录，用户可核对来源后粘贴；不会返回空白却无说明。

新增人工核验记录：

- 同济第六版《高等数学习题全解指南》上册：扫描 PDF 第 6–7 页。
- 同济第六版《高等数学习题全解指南》下册：扫描 PDF 第 4–5 页。
- 来源库中误命名为第七版下册、实际与第六版上册完全相同的文件，按相同 Git blob SHA 复用已核验目录，同时保留原有版本纠错说明。

证据标注存于 `public/textbooks/catalog.json` 的 `outlineEvidence` 字段。扫描 PDF 和本机核验截图不随源码发布。

运行提取逻辑测试：`node scripts/check-pdf-outline.cjs`。
