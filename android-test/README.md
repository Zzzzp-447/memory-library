# Android / 卓易通测试包

这是内置页面、可离线制卡的 Android WebView 测试包，供卓易通侧载试用。不是鸿蒙原生 HAP，也没有上架商店。包名 `com.memorylibrary.study`，最低 Android 8.0（API 26），目标 API 34。没有 CPU 专用原生库，可由运行环境选择对应的 WebView。

0.1.1：作答按钮只显示手写叉和勾；导图按学科独立保存，旧版共享导图只迁移到高数；英语等积累类默认空白供自行编辑。其他学科可搜索 Open Library 公开书目、读取公开目录并预览版本后加入导图，也可手动粘贴目录。生成会保留原有分支。中文教材覆盖和公开目录完整性受该服务限制；联网超时或缺少目录会明确提示，不会编造目录。书目查询需要网络，不上传卡片图片，不需要 AI API 密钥。

内置学科收纳、章节、批量图片制卡、手动遮挡、裁剪、图片缩放、翻面和记录对错，以及可编辑导图。使用系统图片选择器，不申请整个相册或存储空间权限；图像与复习记录保存在当前应用的本地 WebView 数据中。JSON 导图通过系统文件保存器导出。

0.1.3 增加 Android 每日复习通知、时间选择、系统权限/设置入口和测试通知，点击进入今日复习。AlarmManager 使用近似时间单次闹钟并每天重新安排，不申请精确闹钟权限；重启/时区变化/升级后恢复安排。只同步复习时间和连续次数到本地原生存储，不读取 WebView 图片。卓易通实际投递能力及省电延迟需真机确认。默认关闭，用户主动开启时才请求 Android 13+ 通知权限。

目前没有账户同步或完整资料库备份。卸载、清除应用数据或清理卓易通内的应用数据会丢失本机卡片。升级测试包请覆盖安装，保留包名和本地测试签名。

## 构建

0.1.2：默认主页为今日复习，资料库移至 `/library`。复习元数据使用可选字段保存到原 IndexedDB，旧卡片自动参与今日队列。前后面、图片缩放与勾叉采用共享组件，章节手动复习也会更新计划。答对采用 1/2/4/7/15/30 天的间隔档位；答错次日重试，连续正确达到可选门槛停止推送。卡片不删除。这里是应用内队列，不包含后台系统通知。

需要 JDK 17、Android API 35 的 `android.jar` 和 build-tools 35.0.0。当前工具下载并解压在 `tooling/` 中，不修改全局环境。

工具来源：

- JDK：https://api.adoptium.net/v3/binary/latest/17/ga/windows/x64/jdk/hotspot/normal/eclipse
- 平台：https://dl.google.com/android/repository/platform-35_r02.zip
- 构建工具：https://dl.google.com/android/repository/build-tools_r35_windows.zip

在 PowerShell 中运行 `./android-test/build.ps1`，或用 `-BuildWeb` 先重新构建网页。脚本使用 javac、D8、aapt2、zipalign 和 apksigner，不依赖 Gradle、Android Studio 或 Rust。

`keys/local-test.keystore` 是仅用于本地测试的签名，不用于商店发布。不要删除，否则后续同包名更新不能直接覆盖当前安装。

## 真机验收

1. 将 `MemoryLibrary-0.1.3-test.apk` 发送到手机，通过卓易通提供的本地 APK 安装入口覆盖安装；入口名称和侧载支持以手机中的卓易通版本为准。
2. 打开 Memory Library，在“制作卡片”选学科和章节，导入两张图片。若图库没有列出手机中的图片，先将图片导入卓易通可访问的文件位置。
3. 亲自裁剪、涂抹答案、撤销、放大移动并检查正背面。
4. 保存第一张，确认自动切换下一张；完成后进章节，翻面并点勾或叉。
5. 完全退出并重新打开，确认卡片和对错记录保留。
6. 在导图连续添加两层分支，确认连接线显示，并试导出 JSON。

网页触屏模拟通过不等于卓易通真机通过。需要特别确认实际运行环境的 WebView 版本、系统图片选择器和数据持久化。
